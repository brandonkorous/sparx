API reference / Commerce / Orders

Create an order.

POST https://api.sparx.works/v1/commerce/orders

Creates a new order in the commerce module. Orders may be retail or B2B; B2B orders accept payment terms and a PO number, and are routed through approval when the customer's credit policy requires it. The created order is returned, and an order.created event is emitted on Pub/Sub.

Body parameters

customerId string Required

The id of the customer placing the order, from the CRM module. Must belong to the same tenant as the API key.

lines array of objects Required

The line items to order. At least one is required. Each line references a variant by sku and a quantity.

sku string Required

The variant SKU. Resolved within the tenant's catalog.

qty integer Required

Quantity to order. Must be ≥ 1.

priceOverride Money Optional

Override the catalog price for this line. Requires the orders:price_override scope.

terms object Optional

Payment terms for B2B orders, e.g. { "type": "net", "days": 30 }. Omit for retail orders paid at checkout.

poNumber string Optional

The customer's purchase-order reference. Shown on the invoice.

metadata object Optional

Up to 50 key/value pairs you can attach for your own bookkeeping. Returned verbatim; never used by Sparx.

Returns

Returns an Order object on success. The order's status is approved for retail and auto-approved B2B, or pending_review when credit policy requires approval. Returns an error object if the customer or a SKU can't be resolved.

Errors

402 · payment_required

The B2B customer has exceeded their credit limit. The order is not created.

404 · sku_not_found

One or more lines[].sku values don't exist in the catalog.

403 · module_disabled

The tenant hasn't activated the commerce module.

Request 
curl https://api.sparx.works/v1/commerce/orders \
  -H "Authorization: Bearer $SPARX_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "customerId": "cus_8R4Xz1QkM",
    "terms": { "type": "net", "days": 30 },
    "poNumber": "PO-8841",
    "lines": [{ "sku": "INJ-6.7-CR", "qty": 8 }]
  }'
const order = await client.commerce.orders.create({
  customerId: "cus_8R4Xz1QkM",
  terms: { type: "net", days: 30 },
  poNumber: "PO-8841",
  lines: [{ sku: "INJ-6.7-CR", qty: 8 }],
});
order = client.commerce.orders.create(
  customer_id="cus_8R4Xz1QkM",
  terms={"type": "net", "days": 30},
  po_number="PO-8841",
  lines=[{"sku": "INJ-6.7-CR", "qty": 8}],
