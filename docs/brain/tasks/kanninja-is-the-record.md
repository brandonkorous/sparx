Project-management **live state lives in kanNINJA**, not in the brain. The `tasks` node holds only the *durable* layer:

- **In kanNINJA:** active cards, assignments, statuses, day-to-day work.
- **In the brain:** the roadmap (phase order — what's next and why), cross-cutting punch-lists that outlive a single card, and the *decisions* behind them (linked to [[lessons-learned]]).

**Why:** card state churns hourly — version-controlling it would be noise and would drift from kanNINJA. Durable *intent* is what benefits from living beside the code.

**How to apply:** a fleeting to-do → kanNINJA. A commitment that shapes future work → a note here, linked from [[open-punch-list]].
