Written at the end of a long session so the next one can pick up without the

## 1. Why this work started

Brandon began sales outreach and found meetpiggles.com unreadable to ChatGPT and
thin for a prospect. Measured causes:

- **Cloudflare blocks AI crawlers.** GPTBot and ClaudeBot get `403 Your request was
  blocked` on meetpiggles.com, getpiggles.com and sparx.works. It is the
  account-level "Block AI bots" setting, not code, and contradicts `app/robots.ts`.
  **Fixed 2026-09-30:** Brandon allowed AI crawlers in Cloudflare; GPTBot and ClaudeBot now get 200 on meetpiggles.com and sparx.works. The TF
  token is DNS-only, so it cannot be put in Terraform until the token gets
  "Bot Management: Edit".
- Pages existed but were orphaned (`/how-it-works`, `/who-its-for` not in nav or
  footer), `/apps/campaigns` 404'd, and the sitemap missed pages.

## 2. What shipped this session (uncommitted, in the working tree)

- **Mega nav** `components/marketing/mega-nav.tsx`: Apps panel (6 groups stacked
  in 3 balanced columns: home+web, sell+people, money+run) and Who it's for panel
  (11 trades). `keepMounted` so crawlers see the links. Silica's

  Free tools / Trust and help; legal row.
- **11 trade pages** `app/for/[trade]/page.tsx` from `content/trades/*.ts` +
  `content/trades/detail/*.ts` (~2,000 to 2,400 words each). Sections: hero with
  `TradeFigure`, problems + turn band, what it replaces, a normal week, apps up
  close, moving over + first hour, cost, FAQ (+ FAQPage JSON-LD), related trades,
  close. Light list for menus in `content/trades/list.ts`.

  `content/apps/chapters/*.ts` where files would pass 250 lines.
  `content/apps/campaigns.ts` created (the 404).
- **Sitemap** now lists how-it-works, who-its-for, status, legal pages and all

- **Soft color pass (Brandon, 2026-09-30):** solid brand colors are the brand;

  success/warning notes, the film's "lit" state, the sanctioned accent wash,

## 3. Verified facts the copy must respect

Measured in code or deploy config. Do not claim otherwise without re-checking.

| Claim | Truth | Where |

| Marketplaces (Amazon, eBay, Etsy, Faire, Walmart, TikTok Shop, Google Shopping, Meta, Pinterest) | **No.** `CHANNELS_TOKEN_KEY` and channel creds only in retired GCP `terraform/envs/prod/serverless.tf` | `wizeworks/packages/channels/src/integration.ts` |

| Gmail / Outlook / Twilio | Unconfirmed (`CRM_MAILBOX_TOKEN_KEY` not in manifests) | |
| Etsy | Import of listings + sold-orders **files** via Move in only | `wizeworks/packages/migration/src/vendors/etsy.ts` |
| Pages/posts import | WordPress, Squarespace, Webflow, Ghost, Framer, Substack, WooCommerce. **Not Wix** | `vendors/*.ts` |

| Customer groups | Purchase-based fields; no booking fields | `crm-schemas` segment rules |
| Automations | No test-run before switching on | |
