# Brand Correction

The canonical Piggles accent color is **pink/coral**, matching the approved Piggles logo board.

The yellow version was an exploratory test only and was rejected.

Canonical direction:

- Piggles pink/coral primary accent
- dark navy/charcoal wordmark and readable text
- pale pink supporting tones
- white/off-white surfaces
- very round primary display typography
- rounded pig-shaped P mark with integrated snout

Any previous references to yellow should be treated as superseded by this document and the updated brand tokens.
