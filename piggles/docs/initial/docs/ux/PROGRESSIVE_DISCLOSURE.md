# Progressive Disclosure

## Principle

Show the common path first. Keep advanced power nearby.

## Standard pattern

1. Common fields
2. More options
3. Advanced

## Product example

Common: name, price, photo, description.  
More: variants, stock, tax, shipping.  
Advanced: metadata, complex pricing, integrations, automation hooks.

## Message example

Common: audience, subject, message, send.  
More: schedule, segmentation, tracking.  
Advanced: automation triggers, variables, integration behavior.

## Site example

Common: page, content, design, pictures.  
More: SEO, forms, reusable pieces.  
Advanced: structured content, developer hooks, custom integrations.

## Rule

Never hide required information under Advanced.
