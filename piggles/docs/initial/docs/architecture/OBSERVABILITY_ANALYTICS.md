# Observability and Product Analytics

## Technical observability

Track request latency, error rate, job failures, queue depth, auth failures, provisioning failures, email delivery, media processing, API/MCP errors, payment webhooks, and entitlement failures.

## Product analytics events

- account_created
- email_verified
- onboarding_started
- onboarding_completed
- workspace_provisioned
- app_enabled
- app_disabled
- window_opened
- workspace_saved
- first_site_published
- first_product_created
- first_customer_created
- first_booking_created
- first_invoice_sent
- first_message_sent
- subscription_started
- capacity_threshold_reached
- capacity_pack_added
- subscription_cancelled

## Brand experiment fields

Preserve acquisition brand (`piggles` or `sparx`), campaign, referrer, landing domain, signup domain, and conversion timestamp so the market test can be measured fairly.
