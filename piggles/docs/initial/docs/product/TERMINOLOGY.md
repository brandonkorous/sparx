| Scheduling             | Bookings              | clear intent                                  |
| Finance                | Money                 | everyday term                                 |
| Team                   | My Team               | ownership                                     |
| Integrations           | Connections           | friendly umbrella                             |

| MDI                    | Workspace / workbench | internal only                                 |
| RBAC                   | Access / roles        | avoid acronym                                 |
| Collection             | Content type / list   | choose contextually                           |
| Price book             | Pricing               | advanced detail only                          |
