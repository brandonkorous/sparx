# Piggles App Inventory

| Customer app | Primary purpose                                | Typical internal capability           |
| ------------ | ---------------------------------------------- | ------------------------------------- |
| Home         | What needs attention now                       | dashboard/activity/task orchestration |
| My Site      | Site design, pages, branding, preview          | builder/CMS/site                      |
| Content      | Articles, reusable content, media              | CMS/content                           |
| Get Found    | SEO and discoverability                        | SEO                                   |
| Sell         | Products, services, checkout, orders           | commerce                              |
| Stock        | Inventory, quantities, locations               | inventory                             |
| Customers    | Customer records, history, notes, segments     | CRM                                   |
| Messages     | Email and customer communications              | email/messaging                       |
| Bookings     | Scheduling and appointments                    | scheduling                            |
| Invoices     | Create, send, track invoices                   | invoicing                             |
| Money        | Revenue, expenses, cash overview, reports      | finance                               |
| My Team      | Team members, access, roles                    | identity/RBAC/team                    |
| Automations  | Repeatable workflows                           | automation                            |
| Partners     | Partner/vendor relationships                   | partner features                      |
| Connections  | External integrations and advanced connections | integrations/MCP/API surface          |

## Naming rules

- Prefer nouns customers already use.
- Avoid acronyms in primary navigation.
- "CRM" and "CMS" may appear in SEO/docs, not normal navigation.
- "MDI" is an implementation term, not product copy.
