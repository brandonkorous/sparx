# Visual Applications

## Leather

Use debossed/stamped warm tan or caramel leather. Prefer mark + wordmark. Omit tiny tagline when scale does not support it.

## Heritage badge

Use as campaign/merch expression, not the default master logo. Keep the modern Piggles mark central while surrounding ornament can vary.

## Embroidery

Simplify fine detail, test minimum stitch size, and use high contrast. Mark-only version must work on hats and bags.

## Enamel

Support mark-only pin, wordmark pin, and combined lockup. Pink + charcoal + metal edge is preferred.

## Neon/signage

Use the mark as the accent and wordmark as white/neutral light where useful. Always provide a non-neon daytime fallback.

## Letterpress/foil

Use for cards, leave-behinds, packaging, and premium collateral. Blind embossing of the mark is encouraged.

## Wood

The mark should survive carved or burned application. Simplify small text as needed.

## Wax seal

Use mark-only. Do not force the wordmark into tiny wax seals.

## Rule

These applications extend the brand; they do not replace the master identity.
