# Usage Matrix

| Asset ID | Primary use | Secondary use |
|---|---|---|
| `piggles-empty` | Empty collections | First-use setup |
| `piggles-error` | Recoverable errors | Validation failures |
| `piggles-loading` | Loading | Long-running work |
| `piggles-no-results` | Search with no matches | Filtered empty state |
| `piggles-upload` | Upload/import | Submit files |
| `piggles-download` | Download/export | Receive files |
| `piggles-security` | Security/privacy | Permissions |
| `piggles-support` | Help/support | Contact us |
| `piggles-maintenance` | Planned maintenance | System configuration |
| `piggles-announcement` | Announcements | Product updates |

Use empty alt text when decorative. For meaningful state illustrations, describe the state or outcome rather than the mascot’s appearance.
