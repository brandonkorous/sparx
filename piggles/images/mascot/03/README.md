# Piggles Mascot System — Batch 03

Ten original Piggles illustrations centered on application states and operational workflows. Every illustration is a genuinely new render built to the canonical `MASCOT.md` v1.1 pattern, with transparent PNG and WebP output.

Batch 03 deliberately uses the full branded canonical presentation for every functional state: natural peach-pink Piggles, the charcoal shirt, and the official pink Piggles `P` centered on the chest. The round silhouette, tiny limbs, brown hooves, compact facial features, and warm upper-left lighting remain consistent throughout.

## Contents

- `assets/png/` — transparent masters
- `assets/webp/` — optimized production derivatives
- `assets/sheets/` — character sheet
- `manifest.json` — asset registry
- `src/` — JavaScript, TypeScript, and React helpers
- `docs/` — character, pose, and usage guidance
