# Piggles Mascot Batch 07

Batch 07 is a static small-business scene collection based on the canonical Piggles specification in `MASCOT.md` v1.1.

Every asset keeps the canonical natural peach-pink Piggles, extremely round proportions, tiny limbs, charcoal shirt, and official pink Piggles P. Scene props use the controlled cream, charcoal, warm-gray, natural-wood, and restrained-pink palette.

## Included scenes

- `piggles-bakery`
- `piggles-barber`
- `piggles-potter`
- `piggles-garage`
- `piggles-market-stall`
- `piggles-salon`
- `piggles-tailor`
- `piggles-art-studio`
- `piggles-workshop`
- `piggles-supplier`
- `piggles-shed`

## Formats

- `assets/png`: transparent PNG masters
- `assets/webp`: transparent lossless WebP exports
- `assets/sheets/piggles-character-sheet.jpg`: labeled overview sheet

Use `src/pigglesCharacters.js` or `src/PigglesCharacter.jsx` when consuming the assets in an application.
