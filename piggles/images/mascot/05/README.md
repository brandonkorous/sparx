# Piggles Mascot System — Batch 05

Ten compact tabletop Piggles illustrations inspired by the friendly laptop-and-desk composition supplied for this batch. The reference guides layout only; every Piggles render follows `MASCOT.md` v1.1 and the approved originals board.

Each asset uses natural peach-pink Piggles, canonical round anatomy, upright medium-small ears, small black eyes, the charcoal shirt, and the official pink snout-bearing Piggles `P`. Props stay within cream, charcoal, warm gray, pale wood, restrained pink, and limited natural green.

## Contents

- `assets/png/` — transparent 1254 × 1254 masters
- `assets/webp/` — optimized production derivatives
- `assets/sheets/` — labeled character sheet
- `manifest.json` — asset registry
- `src/` — JavaScript, TypeScript, and React helpers
- `docs/` — character, pose, and usage guidance

```jsx
<PigglesCharacter id="piggles-laptop-focus" alt="Piggles working at a laptop" />
```
