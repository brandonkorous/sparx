# Piggles Mascot System — Batch 04

Ten original setting-based Piggles illustrations for workplace, commerce, and small-business storytelling. Every asset follows `MASCOT.md` v1.1 and uses the full branded canonical presentation: natural peach-pink Piggles, charcoal shirt, and the official pink Piggles `P`.

## Contents

- `assets/png/` — transparent 1254 × 1254 masters
- `assets/webp/` — optimized production derivatives
- `assets/sheets/` — labeled character sheet
- `manifest.json` — asset registry
- `src/` — JavaScript, TypeScript, and React helpers
- `docs/` — character, scene, and usage guidance

```jsx
<PigglesCharacter id="piggles-desktop-computer" alt="Piggles at the computer" />
```

These are compact environment vignettes rather than full backgrounds. They are designed to drop into marketing sections, onboarding, feature pages, and larger product empty states.
