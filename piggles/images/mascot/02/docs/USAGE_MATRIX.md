# Usage Matrix

| Asset ID | Primary use | Strong secondary use | Avoid |
|---|---|---|---|
| `piggles-point-right` | CTA guidance | Feature callout | Left-edge targets |
| `piggles-coffee` | Friendly welcome | Break/loading state | Urgent errors |
| `piggles-phone` | Mobile/messages | Notifications | Desktop-only concepts |
| `piggles-package` | Orders/delivery | Product launch | Billing failures |
| `piggles-thumbs-up` | Success | Approval | Warnings |
| `piggles-checklist` | Tasks/setup | Completion | Open-ended discovery |
| `piggles-chart` | Analytics | Growth/milestones | Empty data |
| `piggles-welcome-sign` | Onboarding | Greeting | Dense dashboards |
| `piggles-mail` | Email/messages | Campaigns | File uploads |
| `piggles-idea` | Suggestions | Help/discovery | Destructive actions |

Use WebP in production and PNG for editing or environments where lossless masters are preferred. Decorative instances should use an empty alt string; meaningful instances should use concise contextual alt text.
