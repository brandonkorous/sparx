Full section plan

  • Size — width / height (preset + Custom), min & max reveal, aspect, overflow
  • Spacing — padding & margin 4-side box widgets (link-all)
  • Position — static/relative/absolute/sticky → offsets + z-index cascade
  • Borders — width / style / color / radius (+ per-corner)
  • Effects — opacity / shadow / transform (scale·rotate·move) / transition
  • Typography text blocks — font / size / weight / leading / tracking / align / case
  • Custom CSS — the raw class escape hatch

Platform guardrails

  • fixed position is blocked → not offered
  • z-index is scale-only z-0…z-50 → stepped select
  • colors are token-only → swatches, never raw hex
  • everything else takes arbitrary values (20px, 50%) — real Tailwind JIT, renders in canvas + live site

On modals

In a ~360px panel, cascading reveals + popovers beat modals. I'd only use a modal for a genuinely large editor (e.g. a multi-stop gradient) — not needed yet.
